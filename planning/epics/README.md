# Draft epics

These are starting points for discussion, not committed scope or tracked
work items. See the [glossary](../glossary.md) for domain terms.

The candidate KPIs focus on conservation and public benefit rather than
revenue. Establish a baseline, reporting frequency, eligibility criteria, and
targets with staff and a seed-bank specialist; none are prescribed here. For
snapshot percentages, use the active collection at the reporting date.

- [E-1: Register and describe seeds](register-and-describe-seeds/README.md)
- [E-2: Track inventory and storage](track-inventory-and-storage/README.md)
- [E-3: Monitor seed health](monitor-seed-health/README.md)
- [E-4: Regenerate seed collections](regenerate-seed-collections/README.md)
- [E-5: Manage requests and distribution](manage-requests-and-distribution/README.md)
- [E-6: Protect and trace the collection](protect-and-trace-the-collection/README.md)

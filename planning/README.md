# Seed bank planning notes

These are temporary notes for shaping a training project, not a kanban board
or a set of tracked work items. They can later inform a board outside the
repository.

- [Draft epics](epics/README.md)
- [Domain glossary](glossary.md)

The working assumption is a conservation seed bank rather than a commercial
seed retailer. Domain terminology and workflows should be reviewed with a
seed-bank specialist before treating them as requirements.

Each epic has its own folder and overview. As features are broken down, their
user stories can be kept in the epic's `features` folder.

Work item identifiers use `E-` for epics, `F-` for features, `US-` for user
stories, and `T-` for tasks. Identifiers are unique within each type across
the planning notes. Keep existing identifiers when reorganizing items, and
assign new numbers rather than reusing retired identifiers.
